# Rldcoin public website

- This is the independent English website for rldcoin.com, not the protocol/node repository or the wallet application.
- Use the published genesis records and versioned protocol release as sources. Never copy private keys, local evidence, backups, operator files, or node data into this repository.
- Obsolete mainnet material is excluded from this website and from completion evidence. Publish only current testnet and separately scoped ground-candidate material. A future mainnet requires a fresh signed zero-issuance genesis after qualification; test balances and keys never become mainnet assets or authority. Keep independent-operation, custody, review and physical-route claims tied to actual evidence.
- The future node model is progressive signed neighbor discovery and durable multi-hop relay, with Earth–Proxima Centauri–Andromeda as an illustrative topology. The published contact-spool ground prototype is a separately started supplemental process, not native default discovery or a physical route. Keep transport receipt separate from ledger acceptance, and retain causal light-time, long-term key/archive, independent-operation and real-adapter limits.
- Keep the network status feed read-only, bounded, pinned to the expected network, timestamped, and explicit about stale/unavailable data. It is operator telemetry, not independent verification.
- All navigation and calls to action must lead to real content. Do not add token-sale, wallet-connect, consumer-wallet-download, or price features without an authorized implementation.
- Verify the production build, status freshness/error paths, desktop/mobile navigation, and changed page rendering. Use the existing focused network tests when modifying status handling.
- Vercel project: rldcoin-website. GitHub repository: RunlaiDeng/rldcoin-website. DNS is managed by the owner; do not change it without an explicit request.
- Diagram language: local networks joined by adjacent relays, including stationary habitats and mobile carriers. Network circles are conceptual groupings, never asserted radio ranges or physical overlap; geometry and animations are not distance or travel-time scales. Keep this meaning consistent across the relay atlas, transfer explorer and shared website/PDF figures. General website diagrams use white or near-white surfaces, fine muted blue lines and the site typography; the owner rejected dark blue diagram backgrounds. The white paper uses pure white backgrounds and black text, lines and diagram labels in both its web reader and PDF; distinguish chart series with solid/dashed lines. Respect reduced motion and preserve keyboard operation.
