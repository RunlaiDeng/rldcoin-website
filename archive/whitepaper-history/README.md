# Historical publication artifacts

These files retain superseded public artifacts byte-for-byte. They are outside
`public/`, are not served by the website, and are not current mechanism,
implementation or monetary authority. The canonical current paper and its
publication record remain in `public/documents/`.

`inventory.json` records each former public URL, retained path, exact SHA-256 and
byte length. The old overview and editorial-separation record retain their dates
in their archive filenames. Earlier receipts keep their original bytes and
historical source bindings, even when those bindings describe a superseded
canonical path. Git history retains the original locations and publication order.

The retained `whitepaper_diagrams.py` is a historical generator snapshot, not an
active publishing entry point. The active generator exports only the two figures
bound by the current canonical paper. Historical figures must not be restored to
the website public directory or used as the current mechanism.

Historical failures and limitations remain failures and limitations. Moving the
artifacts changes neither the paper body/PDF nor any protocol, keys, state,
monetary genesis, evidence qualification or network operation.
